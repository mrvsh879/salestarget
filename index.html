План месяца

Считает остаток и дневную норму с учетом выходных (Сб/Вс) + детализация по командам.

План сохраняется для выбранного месяца.
Можно вести прогресс — он тоже сохранится.
По умолчанию выходные не считаются.

Итоги

—
План
0
Сделано
0
Осталось
0
Осталось рабочих дней
0
Нужно в день
0

Команды: план / факт / остаток / нужно в день

Вводи план и факт по каждой команде — система покажет остаток и дневную норму (на оставшиеся рабочие дни). Данные сохраняются для выбранного месяца.
