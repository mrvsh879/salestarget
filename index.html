План месяца

Считает остаток и дневную норму с учетом выходных (Сб/Вс) + детализация по командам + календарь.

План сохраняется для выбранного месяца.
Можно вести вручную или автоматически из календаря (см. ниже).
Если “Факт из календаря” включен — верхний “Факт” считается автоматически.

Календарь (дневная норма)

Клик по дню → введи “Сделано за день”. Календарь пересчитает “Нужно сегодня”, чтобы выйти на план к концу месяца.

Команды: план / факт / остаток / нужно в день

Вводи план и факт по каждой команде — система покажет остаток и дневную норму (на оставшиеся рабочие дни). Данные сохраняются для выбранного месяца.
